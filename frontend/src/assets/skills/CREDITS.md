`sql-dark.svg` / `sql-light.svg` foram criados neste projeto seguindo o
mesmo modelo (256×256, `rect rx="60"`, glifo no bloco central), já que o
repositório não possui um ícone "SQL" genérico (só SQLite/MySQL/PostgreSQL).
